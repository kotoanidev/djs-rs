# djs-builders

Validated builders for Discord embeds, application commands, components and modals.

> **Status:** pre-alpha — this crate is a placeholder and contains no functionality yet.
> Track progress in the [roadmap](https://github.com/kotoanidev/djs-rs/blob/main/ROADMAP.md).

**discord.js counterpart:** `@discordjs/builders`

## Planned scope

- `EmbedBuilder` with Discord limit validation
- Slash and context-menu command builders
- Button, select menu, action row, Components V2 and modal builders

## Part of djs-rs

`djs-builders` is one crate of [djs-rs](https://github.com/kotoanidev/djs-rs), a high-performance
Rust library for building Discord bots modelled on discord.js v14. It can be used on its own
or through the main `djs-rs` crate.
