# djs-collection

A feature-rich map type modelled on discord.js Collection.

> **Status:** pre-alpha — this crate is a placeholder and contains no functionality yet.
> Track progress in the [roadmap](https://github.com/kotoanidev/djs-rs/blob/main/ROADMAP.md).

**discord.js counterpart:** `@discordjs/collection`

## Planned scope

An insertion-ordered map with the full discord.js `Collection` API surface: `find`,
`filter`, `partition`, `sweep`, `first`, `last`, `random`, `sort`, and more.

## Part of djs-rs

`djs-collection` is one crate of [djs-rs](https://github.com/kotoanidev/djs-rs), a high-performance
Rust library for building Discord bots modelled on discord.js v14. It can be used on its own
or through the main `djs-rs` crate.
