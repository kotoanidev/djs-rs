# djs-formatters

Markdown, mention and timestamp formatting helpers for Discord messages.

> **Status:** pre-alpha — this crate is a placeholder and contains no functionality yet.
> Track progress in the [roadmap](https://github.com/kotoanidev/djs-rs/blob/main/ROADMAP.md).

**discord.js counterpart:** `@discordjs/formatters`

## Planned scope

- User, channel, role, slash-command and emoji mentions
- Markdown: bold, italic, underline, strikethrough, spoilers, code, quotes, headings, lists,
  hyperlinks
- Timestamps with every Discord style, and markdown escaping

## Part of djs-rs

`djs-formatters` is one crate of [djs-rs](https://github.com/kotoanidev/djs-rs), a high-performance
Rust library for building Discord bots modelled on discord.js v14. It can be used on its own
or through the main `djs-rs` crate.
